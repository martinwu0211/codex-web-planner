# Plugin maintenance

This repository is a public plugin maintained by its owner for other users.
For owner-requested plugin changes, finish the implementation and relevant checks,
bump the release version, update release notes, and commit and push a new version
to the existing Git remote. Do not leave a completed change only in a local cache.
Include related pending plugin changes requested by the owner; preserve unrelated
work. Do not publish credentials, pairing codes, browser profiles, local state, or
machine-specific paths. Respect an explicit request to defer publishing.
